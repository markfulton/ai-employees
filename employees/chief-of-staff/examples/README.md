# Example output

Everything in this folder is fictional. It is what the Chief of Staff kit writes during one baseline week for Northwind Roofing, a residential and light commercial roofing company run by Sam, with three other AI Employees installed beside it on the same machine: the GTM Engineer, the SEO/AEO Employee, and the Sales Employee.

The week runs from 2026-03-02 to 2026-03-06 and every file is dated the way the routines would have dated it. Nothing here is a real business, a real person, a real domain, or a real run.

Every file passed the kit's own copy check before it was committed, and every run record line validated through the kit's own run log script in dry run mode. The rules those two scripts enforce are the same rules the routines are held to.

| File | What it is |
|---|---|
| `brief-latest.md` | The morning brief `cos-fleet-reconcile` wrote on the Thursday, in the shape its brief template gives |
| `runlog.jsonl` | Three run records from this kit's own log: one ok, one skipped outside its window, one partial |
| `fleet/fleet.json` | The fleet file from the same morning, every Employee and every routine on the machine in one of four states |
| `decisions/REGISTER.md` | The register as re-rendered that morning: three moves from the Friday brief, one accepted, one deferred, one waiting on a tick |
| `dossiers/dossier-seo-employee--seo-publish-run--silent-stop.md` | The dossier for the one fault older than a week, ending in the line to paste |
