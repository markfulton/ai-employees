## How it was done

1. **Phần A once.** Every Phần A clause was classified in `_shared/phan-a-ledger.md`. Sources behind an adopted law, number or platform clause were re-opened on 24/09/2026, and the terms of Google, LinkedIn, Meta, TikTok, YouTube, OpenAI and Cốc Cốc were read for D13. The consequence that shapes the whole variant: no routine queries a search engine's result page, an AI answer surface, or a social, video, professional network or chat platform (D16, D17). A person views and pastes.
2. **One writer per routine.** Each writer extracted its own Phần B, built a clause ledger before editing (ADOPT, MOVE, KEEP, WORDING, EXAMPLE, DEFER, REJECT, UNVERIFIED), edited only its own `SKILL.md` in English with Vietnamese owner lines, kept Step 0, both guardrails, the run record, idempotency and `## Corrections` byte identical, and routed everything outside its file as an outbound deferral or a shared file patch request.
3. **One integrator.** Deferrals aimed at a routine of this kit were applied where the clause carried `[CG]` or an `[S#]` re-opened on 24/09/2026, under the writers' editing rules, and recorded in the target ledger under `### Deferrals received`. Shared file requests were applied in the lead's order and logged request by request in `_shared/patch-log.md`: 51 rows, plus 12 integrator additions that keep the kit consistent with them. New contract material went into a new `CONTRACT.md` section 10, "Vietnam operating rules", at the end of the file (it has no appendix), with every existing section number unchanged. The integrator re-opened no source.
4. **Checks** as listed below. A checker PASS was not treated as proof: every applied deferral and patch was traced to the file that carries it and the routine that reads it.

## How to install this variant

The public npm package does not contain `seo-employee-vn`, and `npx ai-employees hire seo-employee` installs the English kit. Once the lead wires the variant into the fork's bundled installer, install from a checkout of the Vietnam fork:

```
git clone https://github.com/phantanphatdgteam-gif/ai-employees-VN.git
cd ai-employees-VN
git checkout feature/vn-localization
node installer/cli.mjs hire seo-employee-vn --to ~/ai-employees/seo-employee-vn
```

The branch must contain the variant, so it has to be committed and pushed first. A later upgrade uses the same checkout: `node installer/cli.mjs upgrade seo-employee-vn --to <folder>`, then `--apply`. Never run `npx ai-employees upgrade seo-employee` on this folder.
